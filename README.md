# Directives (Layer 1: SOPs)

Store Standard Operating Procedures (SOPs) written in Markdown here.

Each directive should define:
- **Goal**: What needs to be accomplished
- **Inputs**: Required arguments, parameters, or data
- **Tools/Scripts**: Deterministic Python scripts in `execution/` to invoke
- **Outputs**: Expected results or deliverables
- **Edge Cases & Failure Modes**: Learnings and caveats discovered during execution
